# 💬 WhatsApp Bot using Playwright

## 📖 Description

This project automates WhatsApp Web using Python and Playwright. It reads contact names and messages from an Excel file, searches for each contact, and sends personalized messages automatically.

The project demonstrates browser automation and Excel integration.

---

## ✨ Features

- Opens WhatsApp Web
- Reads data from Excel
- Searches contacts automatically
- Sends messages
- Supports multiple contacts

---

## 🛠️ Technologies Used

- Python
- Playwright
- OpenPyXL
